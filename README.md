# Codificação para Back-End

## 📌 Sobre a disciplina

Este repositório reúne os conteúdos, exercícios e projetos desenvolvidos durante a unidade curricular de **Codificação para Back-End**, parte do curso **Programador Full Stack - Programa Autonomia e Renda Petrobras**, oferecido pelo SENAI Macapá.

## 🎯 Objetivos do curso

- Compreender os fundamentos do desenvolvimento back-end e sua integração com aplicações front-end.
- Desenvolver APIs e serviços web capazes de processar, armazenar e disponibilizar dados.
- Aplicar boas práticas de programação, versionamento de código e organização de projetos.
- Trabalhar com banco de dados para persistência de informações.
- Construir uma base sólida para atuação profissional como desenvolvedor Full Stack.

## 🛠️ Tecnologias aplicadas

- Node.js


## 🧰 Ferramentas utilizadas

- **Git e GitHub** — controle de versão e hospedagem do código
- **Visual Studio Code** — editor de código
- **Prompt de Comando / Terminal** — execução de comandos
